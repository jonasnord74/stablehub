# StableHub

Mobilvänlig stallapp med Supabase-inloggning och gemensam hästinformation.

## Publicera med GitHub + Vercel

1. Skapa ett nytt tomt GitHub-repo som heter `stablehub`.
2. Ladda upp alla filer i denna mapp till repots rot.
3. I Vercel: Add New > Project > Import Git Repository.
4. Välj `stablehub`.
5. Framework Preset: Other.
6. Build Command: lämna tomt.
7. Output Directory: lämna tomt.
8. Klicka Deploy.

Efter detta publicerar Vercel automatiskt varje ny commit till GitHub.
